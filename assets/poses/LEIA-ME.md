# Poses

Um PNG por pose, fundo transparente, uma pasta por lutador:

    assets/poses/lucas/00-idle.png
    assets/poses/lucas/01-andar-a.png
    ...

A ordem dos frames e a ordem alfabetica dos arquivos - por isso o prefixo
numerico. Depois rode:

    python tools/atlas.py lucas

Ver ARTE.md para o pipeline inteiro.
